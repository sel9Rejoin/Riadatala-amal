# Riadatala

منصة حجز متعددة الكوتشز (Multi-Tenant): محرك جدولة حتمي منفصل عن محرك المحادثة بالذكاء الاصطناعي، مع واجهة موحدة للتقاويم.

## الحالة
نواة محرك الجدولة جاهزة: توفر بالمناطق الزمنية، حجز مؤقت ثم تأكيد صريح، منع الحجز المزدوج، مزامنة تقويم مع إعادة محاولة وحالة `failed_sync`.

## تشغيل الاختبارات
```bash
python -m unittest discover -s tests -t . -v
```
